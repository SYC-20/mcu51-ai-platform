# 2025AI 教学实验平台 —— 硬件说明（依据原理图 SCH_2025AI教学实验平台_2026-09-29）

## 芯片
- 工作 MCU：STC89C52RC-40I（8051 内核，12T，8KB Flash，512B RAM），晶振 11.0592MHz。学生程序烧写到这颗芯片。
- 协处理芯片：IAP15F2K61S2（LQFP44）。在串口读取模式下负责读取端口状态并模拟按键，供平台自动判分。
- USB 串口：CH340N。负责 STC 串口 ISP 烧写固件与运行状态数据上传。

## 实验的引脚约定
- 指示灯：8 个 LED 接 P1.0~P1.7，**低电平点亮**。P1.0 = LED1（最右侧），P1.7 = LED8。
- 蜂鸣器：接 **P4.2**（STC89C52 LQFP44 扩展口，`sfr P4 = 0xE8;`），经 PNP 三极管 Q3 驱动，低电平导通，**需要输出约 2kHz 方波才会响**。P4.2 的状态无法经串口读到，所以蜂鸣器实验要求同时点亮 LED1（P1.0）作指示。
- 按键：板上是 2×4 矩阵键盘。列线 KEY1~KEY4 接 P2.4~P2.7，行线 IKEY1 接 P3.2（SW1~SW4）、IKEY2 接 P3.3（SW5~SW8）。**要让实体按键当独立按键用，程序先把 P3.3 置 0（示例里 P3.2 也一并置 0）**。实测：SW5~SW8 → P2.4~P2.7（即 key1~key4）；SW1~SW4 在实物板上没有接到 STC89C52，按下无反应，请使用 SW5~SW8，按下后对应 P2.x 读到低电平。平台测评时会直接拉低 P2.4~P2.7，不受行线影响。
- 数码管：4 位共阴极数码管 FJ5461AH。段码接 **P0**（P0.0=a、P0.1=b … P0.6=g、P0.7=dp），经 74HC245 驱动，**高电平点亮**；位选 **P2.0~P2.3 = DIG1~DIG4**（DIG1 在最左），经 ULN2003 驱动，**低电平选通**。
  - 共阴极段码 0~9：`0x3F, 0x06, 0x5B, 0x4F, 0x66, 0x6D, 0x7D, 0x07, 0x7F, 0x6F`。
  - 单位数码管（E5）：只把 P2.0 置 0（P2.1~P2.3 为 1），P0 送段码，第 1 位循环显示 0~9。
  - 多位数码管（E6，动态扫描显示 1234）：每次只选通一位，送对应段码，停留 1~5ms 后换下一位；完整扫一轮不超过 20ms 就看不出闪烁。换位前先 `P0 = 0x00` 消隐，可防止重影。
  - 串口只能读到 P0 段码，读不到 P2 位选；另外原理图上 P0.1 未接入读取通道，读到的 b 段恒为 1。所以平台按段码的内容、出现顺序和时间判分，并忽略 b 段（数码管上 b 段显示正常）。

## 常见问题
- 全部 LED 不亮：检查是否写成了高电平点亮（P1 = 0xFF 是全灭）。
- 流水灯方向反了：从右到左应是 P1.0 → P1.7，即 `P1 = ~(1 << i)`；`~(0x80 >> i)` 是从左到右。
- 延时不准：软件 for 循环延时与编译器相关（Keil 与 SDCC 生成的代码不同），推荐用定时器 0 方式 1：
  1ms 初值 TH0=0xFC, TL0=0x66（11.0592MHz/12 = 921.6kHz，1ms ≈ 922 个机器周期）。
- 按键无反应：确认读取的是 P2.4~P2.7、判断条件是 `== 0`，并且已经把 P3.2、P3.3 置 0。
- 蜂鸣器不响：确认操作的是 P4.2 而不是 P1.0，并且输出的是方波而不是一直低电平。
- 数码管全不亮：段码要高电平点亮（共阴极），位选 P2.0~P2.3 要置 0。
- 数码管显示乱码：检查段码表是否是共阴极段码，P0.0 对应 a 段。
- 动态显示闪烁或重影：每位停留太久会闪，换位前没消隐会重影。
- 下载失败：STC89 需要冷启动下载——先发送 0x7F 同步，再给板子断电/上电；检查 COM 口是否被其他软件占用。

## 平台编译器
平台使用 SDCC 编译。Keil 写法（`#include <reg52.h>`、`sbit LED = P1^0;`、`interrupt 1`、`code`）会被自动转换。
