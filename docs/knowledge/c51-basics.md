# C51 编程速查

## 端口操作
- 整口赋值：`P1 = 0xFE;`（仅 P1.0 为低电平 → LED1 亮）
- 位定义：`sbit LED1 = P1^0;`，然后 `LED1 = 0;`
- 取反：`P1 = ~P1;`
- 循环移位：`#include <intrins.h>` 中 `_crol_/_cror_`（SDCC 无此函数，可用 `(v << 1) | (v >> 7)`）

## 定时器 0 方式 1（16 位）
```c
TMOD = (TMOD & 0xF0) | 0x01;
TH0 = 0xFC; TL0 = 0x66;   // 1ms @ 11.0592MHz
TR0 = 1;
while (!TF0); TF0 = 0;
```

## 平台要求的标准函数

使用本平台时，学生程序**必须**包含以下标准函数，这是本平台的编程约定，
平台在烧写固件时据此把检测程序与学生程序合成一份固件：

```c
void main(void)   // 标准入口函数，平台内部作为 __student_main 调用
```

- 必须写成 `void main(void)`，不能写成 `int main()` 或带参数的形式，否则编译会提示找不到入口函数。
- 学生程序不需要、也不应该去改动固件或检测程序，检测程序由平台在烧写时加入。

## 按键消抖
按下检测到低电平后延时 10ms 再确认一次，等待松开 `while (KEY1 == 0);`。

## 蜂鸣器
有源蜂鸣器直接低电平驱动即可；无源蜂鸣器需要输出方波：`BEEP = ~BEEP; delay_us(250);`（约 2kHz）。
